# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, welcome newcomers, critique ideas rather than people, and keep
discussions about the work. Harassment, insults, discriminatory language and publishing other people's
private information are not tolerated in any project space (issues, pull requests, discussions).

## Reporting

Report unacceptable behaviour privately to the maintainers through GitHub: open a
[private security advisory](https://github.com/jeremygideonbareh/enginelab/security/advisories/new)
marked "Code of conduct", or contact a maintainer through their GitHub profile. Reports are handled
confidentially. Maintainers may remove comments, commits or contributions, and may ban contributors,
for behaviour that breaks this code.
