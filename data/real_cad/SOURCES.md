# Real CAD used for training and testing

None of these files are in the repository. Download them from the sources below into `data/real_cad/<folder>/` to retrain or re-test. Only the three sample robots are redistributed (as a release asset), under their own licences.

| Folder | Source | Licence | Use |
|---|---|---|---|
| voron24, trident, voron0, switchwire, minisb | github.com/VoronDesign | GPL-3.0 | training (not redistributed) |
| open6x | Open6X robot arm | MIT | training |
| odri_biped, odri_quad12, odri_quad8, odri_trifinger | github.com/open-dynamic-robot-initiative/open_robot_actuator_hardware | BSD-3-Clause | training; biped shipped as beta sample |
| so100, so101 | github.com/TheRobotStudio/SO-ARM100 | Apache-2.0 | training; SO-101 shipped as beta sample |
| koch_follower, koch_leader | github.com/AlexanderKoch-Koch/low_cost_robot | MIT | training; follower shipped as beta sample |
| moveo | github.com/BCN3D/BCN3D-Moveo | MIT | training |
| rebot | github.com/Seeed-Projects/reBot-DevArm | CERN-OHL-W-2.0 | training |
| sesame | github.com/dorianborian/sesame-robot | Apache-2.0 | training |
| robodog | github.com/Josaphat-PRIME/ROBOT_DOG_CAD_FILES | MIT | training |
| openatc | github.com/sn3ro/OpenATC | MIT | training |
| osr_pcb | github.com/nasa-jpl/open-source-rover (electrical 3D models) | Apache-2.0 | training (electronics) |

| test_engines/eng_a, eng_b, eng_c | public GitHub repos without a licence | all rights reserved | local testing only, never published |
